# New World Atlas

Генератор карт для ГМа: от галактик до комнат, с переходом вглубь по клику. Самостоятельное приложение и ядро без DOM,
которое встраивают Marinara Worlds. Замысел, устройство и дорожная карта — в [docs/DESIGN.md](docs/DESIGN.md).

## Запуск

```bash
npm install
npm run dev        # приложение на http://localhost:5173
npm run check      # типы, регрессии ядра, граница ядра
npm run build      # приложение в dist/
npm run build:lib  # ядро одним модулем: dist/lib/new-world-atlas-core.mjs
```

## Что готово: уровень «планета» (этап 1)

- **Рельеф.** Сетка Вороного на 3–50 тыс. ячеек, 10 шаблонов суши (континенты, архипелаг, пангея, острова, полуостров,
  перешеек, внутреннее море, раздробленные земли, фрактал) и фрактальная детализация берегов.
- **Климат.** Температура от широты и высоты; осадки, которые несут пассаты, западные и полярные ветра, с дождевой
  тенью гор.
- **Вода.** Котловины заполняются озёрами, реки стекают по рельефу, собирают притоки, у них есть расход (м³/с) и
  длина (км).
- **Биомы.** 12 типов по температуре и влажности: от жарких пустынь до тайги, ледников и болот.
- **Народы.** У каждого свой процедурный язык (фонология, слоги, морфемы) и свой уклад (мореходы, кочевники, горцы,
  речные, озёрные, охотники); народы расселяются по удобной для себя земле.
- **Государства.** Растут от столиц по стоимости пути и получают форму по размеру и укладу (королевство, империя,
  республика, теократия, орда, вольный город…). У них есть дипломатия с соседями (союз, вражда, вассалитет) и
  провинции.
- **Города.** Население, порты, стены, цитадели, храмы, рынки.
- **Дороги.** Тракты между столицами, сеть дорог и троп внутри государств, морские пути между портами.
- **Достопримечательности для ГМа.** Вулканы, рудники, пещеры с обитателями, руины, поля битв, монастыри, разбойники,
  постоялые дворы, затонувшие корабли, порталы — у каждой своя легенда.
- **Рендер.** 5 стилей (атлас, пергамент, политическая, рельеф, ночь / sci-fi) и 14 слоёв. Значки гор и лесов,
  подписи рек вдоль русла, роза ветров, масштаб, сетка.
- **Приложение.** Масштаб колесом, перетаскивание; клик по карте показывает всё о месте; списки государств, народов,
  городов, рек и достопримечательностей с переходом к ним на карте. Имена латиницей или кириллицей, интерфейс RU/EN.
  Выгрузка в SVG, PNG и JSON со всеми данными.

## Что готово: уровень «город» (этап 2)

- **Пять эпох.** Средневековье и Новое время растут кварталами вокруг рынка; индустриальная эпоха, современность и
  киберпанк строятся районами с сеткой улиц, у каждого района свой угол.
- **Стены.** Башни, ворота и цитадель; в Новое время — звёздные бастионы.
- **Улицы.** Главные улицы от ворот к рынку, дороги за город. В плановых городах — проспекты, кольцевые и радиальные
  магистрали, железные дороги и эстакады (киберпанк).
- **Вода.** Море с изрезанным берегом, река с мостами; на воде ничего не строится.
- **Застройка.** Узкие участки вдоль улиц, патрицианские дома с дворами, трущобы, склады гавани, кладбище, сады,
  полосы полей и слободы вдоль дорог. Даунтаун, торговые районы, жилые кварталы, промзоны, порт, кампус; в киберпанке —
  аркология, мегаблоки и боевые зоны. На больших картах детализация укрупняется, чтобы карта оставалась быстрой.
- **Места для ГМа.** Колодец на площади, храм, донжон, таверны у ворот, кузница, гильдия, баня, виселица, доки,
  мельница; вокзал, больница, стадион, университет; штаб-квартира корпорации, риппердоки, логово нетраннеров, ночной
  рынок, клубы, спуски в нижний город.
- **Рендер.** 5 стилей (тушь, цвет, пергамент, чертёж, неон) и 9 слоёв. Тени у высоток, неоновые контуры, названия
  улиц вдоль трасс, масштаб в метрах.
- **Связь с планетой.** Кнопка «Открыть карту города» у любого города планеты: город получает население, море, реку,
  стены, цитадель, порт, трущобы и язык своего народа.

Тот же сид и те же настройки всегда дают тот же мир; сид попадает в адрес страницы, так что ссылкой можно поделиться.
