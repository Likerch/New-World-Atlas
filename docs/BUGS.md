# Найденные ошибки

Ошибки, которые нашли 13 агентов при разборе проекта (ноябрь 2026). Отмеченные **[x]** исправлены.

Пункты с пометкой **→ A** — это скорее недостающая возможность, чем ошибка. Они переехали в [IDEAS.md](IDEAS.md), часть A. С пометкой **→ B** — в режим игры (часть B).

## Мир, связи и ключи правок
- [x] Планета, открытая из системы, брала параметры прошлой планеты и теряла эпоху (`planet.tsx` load).
- [x] Город, открытый из региона, получался другой картой, чем тот же город с планеты.
- [x] `cityFromBurg` строит сид из копии в регионе, а не из исходного объекта (`origin`). Море и реку ищет только у соседних клеток.
- [x] Ключ правок — только сид. Тот же сид с другим шаблоном, детализацией или охватом получает чужие метки и имена. Это касается планеты, местности, галактики и вселенной.
- [x] Метки и туман здания общие для всех этажей и для комнаты крупным планом.
- [x] Добавленные ГМом города нумеруются по месту в списке: если удалить ранний, сдвинутся поздние (`edit.ts`).
- [x] Мазок рельефа перенумеровывает города и державы. Имена, заметки, переносы и дочерние карты указывают не туда.
- [x] Переименования на вселенной и в подземном мире не применяются (нет `renameUniverse`, `renameUnderworld`).
- [x] Имена и заметки комнат здания нигде не показываются. Имя здания с карты города не доходит до плана.
- [x] Здание, открытое из квартала крупным планом, получает другой сид, чем то же здание с карты города.
